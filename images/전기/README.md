## 파일 이름 규칙

**타입별로 넣기 (권장)** — 같은 타입 세대에 전부 똑같이 보입니다.

```
59C_1.png   59C_2.png   59C_3.png   …   59C_10.png
59A우_1.png  59A좌_1.png  52B_1.png   …
```

**특정 세대만 다르게 넣기** — 그 세대에서는 이 파일이 우선합니다.

```
102_1902_1.png   102_1902_2.png   …
(동_호수_번호)
```

- 확장자는 png, jpg, jpeg, webp 중 아무거나 됩니다. (도면은 선이 또렷한 **png** 를 권장)
- 번호는 1번부터 차례로, 한 세대당 최대 12장까지 찾습니다.
  (더 필요하면 `settings.js` 의 `electricPlanMax` 숫자를 올려주세요)
- 중간 번호가 비어 있어도 있는 것만 보여줍니다.

## 해상도 기준 (PDF → 그림으로 바꿀 때)

- A3 한 장을 **200DPI** (3309 × 2339 픽셀) 로 바꿔 올렸습니다. 사이트의 "🔍 크게 보기"에서
  휠 / 두 손가락 / ＋－ 버튼으로 확대하면 작은 글씨와 치수까지 읽힙니다.
- 흑백 도면은 **8비트 그레이 PNG** (한 장 약 0.3MB), 붉은 표시가 들어간 몇 장만 컬러로 두었습니다.

## 탭 이름

탭 이름은 `names.json` 에 타입별로 적혀 있습니다. (예: 전열 · 벽체배치 · 전등 · 슬라브 기구 · 주방 입면 · 욕실 입면 · 통신 · 범례)
파일 순서(번호)와 이름 순서가 같아야 하므로, 도면을 추가·교체하면 `names.json` 의 같은 타입 줄도 맞춰 주세요.
`names.json` 에 없는 타입은 "도면 1, 도면 2 …" 로 나옵니다.

사이트에서 세대를 열고 **수정 → 도면 이름** 에서 바꿔 저장하면 그 타입 전체에 적용되고,
그 이름이 `names.json` 보다 우선합니다. (지우면 다시 `names.json` 이름으로 돌아옵니다)
