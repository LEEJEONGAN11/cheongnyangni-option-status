# 평면도 이미지 올리는 방법

이 폴더(`images/`)에 파일을 올리면, 사이트에서 자동으로 찾아서 보여줘요. 별도로 코드를 만지거나 저장 버튼을 누를 필요가 없습니다 — 파일만 올리면 다음 접속부터 바로 반영돼요.

## 파일 이름 규칙 (중요!)

```
{TYPE}_{기본형 또는 확장형}.jpg
```

- 예: `84_기본형.jpg`, `84_확장형.jpg`, `59A_기본형.jpg`
- 확장자는 `.jpg`, `.jpeg`, `.png`, `.webp` 중 아무거나 가능해요.
- TYPE 코드와 "기본형"/"확장형" 사이는 반드시 밑줄(`_`) 하나로 구분해주세요.
- 대소문자, 띄어쓰기까지 정확히 맞춰야 인식돼요 (예: `59a_기본형.jpg` ❌ → `59A_기본형.jpg` ⭕).

## 사용 가능한 TYPE 코드 (총 19종)

```
43, 48A, 48B, 52A, 52B, 52C, 55A, 55B,
59A, 59B, 59C, 59D, 59E, 59F, 65A, 65B,
68, 79, 84
```

## 업로드 방법 (Git 몰라도 됩니다)

1. GitHub 저장소 페이지에서 이 `images` 폴더로 들어갑니다.
2. `Add file` → `Upload files` 버튼을 클릭합니다.
3. 평면도 이미지 파일을 위 이름 규칙에 맞게 이름을 바꾼 뒤 끌어다 놓습니다 (또는 파일 선택).
4. 아래 `Commit changes` 버튼을 누르면 끝입니다.
5. 잠시 후(보통 1분 이내) 사이트에서 새로고침하면 바로 보입니다.

같은 이름으로 다시 올리면(덮어쓰기) 이미지가 교체돼요.
