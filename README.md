# 청량리역 요진 와이시티 — 옵션 정리 사이트

접속하면 먼저 **어떤 표를 볼지 고르는 화면**이 나오고, 거기서 두 갈래로 들어갑니다.

| 페이지 | 파일 | 내용 |
|---|---|---|
| 첫 화면 | `index.html` | 둘 중 하나 고르기 |
| 호수별 옵션 계약 현황 | `contract.html` | 155세대 옵션 계약 현황 · 항목별 PDF 출력 |
| 전기공사 옵션 | `electric.html` | 단위세대 전기공사 7품목 · 세대별 전기 도면 |

두 표 모두 **세대를 눌러서 내용을 고칠 수 있고**, 고친 내용은 구글시트에 저장돼서
다른 사람이 열어도 똑같이 보입니다. (비밀번호를 넣어야 수정할 수 있습니다.)

---

## 폴더 구성

```
index.html          첫 화면 (선택)
contract.html       옵션 계약 현황표
electric.html       전기공사 옵션표
config.js           ★ 이 파일만 직접 고칩니다 (서버 주소)
data.js             원본 데이터 (155세대) — 자동 생성, 손대지 마세요
store.js            수정 내용 저장/불러오기
plans.js            도면 보여주기
editui.js           수정 화면
style.css           디자인
images/             세대 평면도 (59C_확장형.jpg …)
images/전기/         ★ 전기 도면 넣는 곳
apps-script/
  Options.gs        구글시트 저장용 서버 코드
```

## 처음 한 번만 하는 준비

수정 기능을 안 쓰실 거면 이 준비는 **안 하셔도 됩니다.** 표는 그냥 열립니다.

1. 구글시트를 새로 하나 만듭니다. 주소창의
   `docs.google.com/spreadsheets/d/`**`이 부분`**`/edit` 을 복사해둡니다.
2. [script.google.com](https://script.google.com) → 새 프로젝트 → `apps-script/Options.gs` 내용을 붙여넣습니다.
3. 맨 위 `setup()` 함수 안의 두 줄을 채웁니다.
   ```js
   var 시트ID = '아까 복사한 것';
   var 수정비밀번호 = '0000';      // 원하시는 숫자로
   ```
4. `setup` 을 한 번 ▶ 실행합니다. (권한 확인 창이 뜨면 허용)
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**

   → 배포 → 나온 주소 복사
6. `config.js` 를 열어 `apiUrl` 에 그 주소를 붙여넣고 저장합니다.

> `config.js` 는 **여러분 파일**입니다. 앞으로 새 버전을 받아 다른 파일을 전부 덮어써도
> 이 파일만 그대로 두시면 설정이 유지됩니다.

## 쓰는 법

**보기** — 그냥 들어가면 됩니다. 아무 설정도 필요 없습니다.

**수정하기**

1. 오른쪽 위 `✏️ 수정하기` → 비밀번호 입력 (이름도 같이 넣으면 이력에 남습니다)
2. 세대를 클릭 → **수정** 탭
3. 체크하고 **저장**
4. 잘못 고쳤으면 **원본으로 되돌리기**

수정한 세대는 골구도에서 **파란 테두리**로 표시됩니다.
`서버 연결됨` 칩을 누르면 누가 언제 무엇을 고쳤는지 **이력**을 볼 수 있습니다.

## 전기 도면 넣기

`images/전기/` 폴더에 파일을 올리기만 하면 됩니다. 자세한 이름 규칙은
`images/전기/README.md` 를 봐주세요. 요약하면:

- 타입별: `59C_1.jpg`, `59C_2.jpg` … (한 세대당 최대 8장)
- 특정 세대만 다르게: `102_1902_1.jpg`
- 탭 이름("조명", "콘센트" …)은 사이트에서 **수정 → 도면 이름**으로 바꿉니다

---

## 알아두시면 좋은 것

- 원본 데이터는 사이트 안(`data.js`)에 들어 있어서, **서버가 죽어도 표는 그대로 보입니다.**
  이때는 화면 위에 "연결 실패" 안내가 뜨고 원본 값으로 표시됩니다.
- 서버에는 **바뀐 것만** 저장됩니다. 시트가 비어 있으면 완전한 원본 상태라는 뜻입니다.
- 비밀번호는 브라우저를 닫으면 풀립니다. (같은 탭에서는 계속 유지)
- PDF는 브라우저 인쇄 기능을 씁니다. 인쇄 창에서 대상을 "PDF로 저장"으로 고르면 됩니다.
